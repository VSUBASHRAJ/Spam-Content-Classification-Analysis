# Spam-Content-Classification-Analysis


## Overview

This project focuses on analyzing and classifying spam-related text content using structured moderation guidelines. The dataset contains user-generated text samples categorized into different moderation classes such as Spam, Safe, Promotional, Offensive, and Harmful content.

The objective of this project is to understand Trust & Safety workflows, content moderation practices, and policy-based classification processes commonly used in digital platforms.

---

## Project Objectives

* Review and classify text-based content
* Identify spam and policy-violating messages
* Understand moderation workflows
* Improve analytical thinking and content evaluation skills
* Maintain consistency in moderation decisions

---

## Dataset Information

The dataset used in this project contains:

* 200+ text samples
* Content classification labels
* Policy status categories

### Classification Categories

* Safe
* Spam
* Promotional
* Offensive
* Harmful

### Policy Status

* Safe
* Policy-Violating
